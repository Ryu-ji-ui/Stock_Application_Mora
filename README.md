# Stock_Application_Mora

An AI-powered stock analysis and investment platform with a React frontend and Flask backend.

## Overview
This project combines stock data, technical and fundamental analysis, sentiment insights, and machine learning-based predictions in a single application.

## Stack
- Frontend: React, Tailwind CSS
- Backend: Flask, SQLAlchemy
- Data and AI: yfinance, pandas, scikit-learn, TextBlob

## Structure
- backend/: Flask API services and models
- frontend/: React application UI
- database/: SQL schema
- scripts/: startup helpers

## Getting started
1. Install backend dependencies from backend/requirements.txt.
2. Install frontend dependencies with npm install in frontend/.
3. Start the backend and frontend using the scripts in scripts/.
